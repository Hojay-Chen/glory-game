glory-game（《廿四争锋》/ Project ARENA·24）的用户是项目的所有者兼创意总监，独立推进。
他给 UX 的简报**非常具体**：直接点名交付物路径、列出必须覆盖的条目、给出约束（不写代码实现、
布局要给数值、IP 合规、以 GDD 为准）。

**协作偏好**：当简报**明确点名输出文件**（如「写一份 docs/ux/ui-spec-v1.md」）并要求「完成后回报文件路径」时，
他是要**直接产出文件**，而不是先走逐节确认/写前审批流程。此时应交付 + 在正文与回报里列出待裁定项，
而不是卡在提问环节。
