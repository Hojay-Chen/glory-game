- 假设 1：§14.1.7 官方连招模板逐帧复现（帧数据 0 误差）

## Findings（详见 AUDIT-REPORT.md §5）

- **F1（设计）**「浮空四连刺」不可复现：浮空空气窗 0.67s 只够 1 刺，模板要求 4 刺 → 需设计裁定（空中普攻形态/浮空时长/攻速）
- **F2（设计）**「标准起手」末端断链：豪龙破军无【扫地】，对倒地目标打不中 → 模板或技能标签需改
- **F3（数据）**落花掌>天击硬链接不成立：吹飞硬直 12f < 攻击方后摇 16f+走位
- **F4（数据）**幻影龙牙 CSV 自相矛盾：active 12f < 5 段×3f 间隔（需 15f）
- **F5（实现，已修）**发射双结算 / 延迟爆发丢失——白盒首跑暴露并修复
- 闸门：BMG 穷举 0 违规，单连段峰值 27.9% HP，最长 1.6s；闸门①⑤在本职业内无压力（无二段浮空源），Alpha 期补压测

**假设判定**：1=部分成立（帧层 20/20 ✓，模板 2/4 断链）；2=成立（BMG 内）；3=待实机。
