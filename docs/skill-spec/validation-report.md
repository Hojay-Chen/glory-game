## 习得模型（learn_level + acq_type 为原著主轴；tier 为竞技档位，两者解耦）

| acq_type | 含义 | learn_level |
|---|---|---|
| normal | 常规习得 | 原著明确等级照录；无记载的由本作拟定 |
| job_change 转职 | 20 级转职后习得（散人不可学） | 20 |
| awakening 觉醒 | 50 级觉醒（散人不可学） | 50 |
