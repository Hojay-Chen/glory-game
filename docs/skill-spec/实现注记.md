# Skill-Spec 实现注记（特殊规则语义）

| 项 | 值 |
|---|---|
| 版本 | v0.1（对应 skills.csv 532 行 / GDD v0.3） |
| 用途 | 只覆盖**无法用一行数值表达的技能**：实现语义、判定时机、状态机、边界情况。数值一律查 `skills.csv` |
| 约定 | 每条注记以 SkillID 开头；「实现」= 程序语义；「反制」= 对手可见的应对窗口 |

## 0. 全局实现规则

- **抓取（type=grab）**：无视普通霸体、不无视无敌帧；对倒地目标一律无效；命中后目标进入 Grabbed 状态（免疫其他来源，§7.1）；命中瞬间 Hitstop 10f；投掷落点/方向按各行 special 标注可控
- **反击（type=counter）**：前摇区间=架势判定窗（各行帧数据）；架势内被近战命中 → 消耗架势转专属反击；空放=吃满后摇且倍率取空放值（若有）；架势窗不提供无敌（除非 invincible_f 单独标注）
- **Channel（channel=1）**：持续施放；被任何硬直打断即终止（已结算段数保留）；不可移动（除非标注）
- **部署（type=deploy）**：生成实体（HP/存在时长见 notes/hitbox）；实体可被双方攻击；死亡/到期返还资源
- **召唤（type=summon）**：单位 AI 固定行为模式（GDD §14.3/14.12），不可微操；继承面板 25–30%（各行 notes）；不提供无敌帧
- **stance（形态切换）**：公共 CD 1.5s；切换动作 8f 可被打断；切换不重置已附着状态
- **蓄力（special 含蓄力）**：长按增强；蓄力中移速惩罚见各行；松手=按当前蓄力档结算；被打断=技能作废 MP 不退
- **拖拽/拉拽**：目标位移由施法者控制方向；被拖者不进入硬直（噬魂血手规则，原著）除非另行标注
- **禁足（六星光牢）**：完全行动剥夺（含位移/普攻/技能），仅保留受击结算；无法被净化/施法者死亡解除
- **破霸体/无视霸体**：命中时清除目标霸体状态（前者）或绕过霸体效果直接生效（后者）；不伤害无敌帧
