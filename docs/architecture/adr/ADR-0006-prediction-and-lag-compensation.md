## 0. 背景

GDD §24.2/24.3 定了框架（本地输入即时预测、服务器确认和解、回溯 ≤200ms、60tick ring buffer）。ADR-0001 的 Determinism Contract 使「客户端重演服务器模拟」在数学上成立——本 ADR 把它落成协议。

## 1. 预测范围（严格限定）

| 内容 | 是否预测 | 理由 |
|---|---|---|
| 本机移动/跳跃/翻滚 | ✅ 预测 | 响应性必需（GDD §24.2） |
| 本机普攻/技能**前摇表现** | ✅ 预测（表现级） | 动画即时启动；**命中与结算不预测** |
| 命中/伤害/几率/状态 | ❌ 服务器权威 | ADR-0003 事件流到达（可靠有序） |
| 对手行为 | ❌ | 对方输入未达；由快照插值显示 |
| 其他 Fighter 的可见交互 | ❌ | 同上 |

- 预测的实现 = **客户端本地跑同一 Arena.Core**（ADR-0009 ISimDriver.OnlinePredicted）：本地输入即时入 CmdStream → 本地预测 Sim 推进 → 服务器权威快照到达后 reconcile
- **预测不消费 RNG**（ADR-0001 §4.1）——几率类结果永远等服务器事件；预测路径若触发含 roll 的效果（本地预判施放），表现只播前摇，效果等权威事件

## 2. 和解（Reconciliation）协议

```
客户端 Tick c：本地 Sim 预测推进（预测指令=本地输入）
服务器 Tick s（权威）：Sim.Step(s, commands[s]) → Snapshot(s) + Events(s)
和解：
  ① 收到 Snapshot(s)，其中 lastProcessedInput = 客户端已被采纳的最近输入 Tick
  ② 本地预测历史中找到 Tick s 的预测快照
  ③ 逐字段比对（位置/状态/资源——Fixed Raw 级）
     ├─ 一致（<ε 无关紧要：定点无 ε，逐位一致或不同）→ 继续预测
     └─ 不一致 → 回退到权威 Snapshot(s)，用本地已确认输入之后缀重演至当前 c
  ④ 纠偏呈现：位置差 > 阈值(0.5m) → 平滑插值过渡 ≤100ms（GDD §24.2）；方向/状态直接切换
```

1. **逐位判定而非容差**：定点体系下预测与权威的输入相同时**必然逐位一致**——不一致即输入集不同（本地多预测了未确认输入），无需容差比较；平滑只作用于**表现呈现**
2. 预测历史缓冲：客户端保留最近 240 Tick 预测快照（4s 上限，超出强制硬重置到权威）
3. 预测误差率 Telemetry 上报（TR-live-001 关联）——纠偏频率是手感质量指标

## 3. 回溯延迟补偿（Lag Compensation，服务器侧）

```
攻击方 Tick t 施放，生效帧 f=t+startup（技能数据）
服务器在 Tick f 结算时：
  目标位置 ≠ 当前位置（目标在 f−delay 时的位置才是攻击方所见）
  → Net.Rollback ring buffer 取 Snapshot(f − roundTripHalf)，用其中目标的
    位置/朝向/状态做命中判定（HitResolve 输入=攻击方当前判定体 × 目标历史判定体）
  → 判定结果作用于目标的【当前】活体状态（扣血/浮空全部在现在时结算）
```

1. **ring buffer**：深度 12 Tick（200ms @60Hz，GDD §24.3），存只读 Snapshot（位置/朝向/状态/高度/判定体）——architecture.md API Boundaries 契约不变：**历史只读、写入只在现在时**
2. **越界策略**：请求的历史 Tick 超出环深 → 退化为当前快照判定 + Telemetry 告警（不拒绝结算——行为降级明确且确定）
3. **结算幂等**（承接 architecture.md）：回溯只提供判定位置；伤害/事件结算发生在生效帧 Tick 恰好一次——SimEvent 唯一键保证重复投递无害
4. **确定性保持**：ring buffer 内容本身是确定重演的产物（同指令流重演 → 相同历史）——回溯判定可被 Replay 完整复算（反作弊审计闭环，TR-net-006）
5. **回溯与受击方体验的权衡**：GDD §24.3 已接受（攻击方公平优先）；受击方看到的被击中位置由其本地插值显示，事件含攻击方判定用的历史位置字段（表现层可选做受击回拉提示——表现决策，非本 ADR 范围）

## 4. 与 Hitstop 的边界（重申用户修正）

Hitstop 只冻结表现时轴；**预测推进、和解、回溯全部不感知 Hitstop**——网络延迟问题由本 ADR 机制解决，Hitstop 纯观感（GDD §24.2「掩盖」仅指观感层）。

## 5. 测试

| # | 测试 | 验证 |
|---|---|---|
| T34 | 和解一致 | 模拟 RTT 80/150/250ms 注入 ⇒ 和解后预测状态与权威逐位一致，纠偏次数符合预期 |
| T35 | 回溯判定 | 构造历史位置命中/当前不命中（反之亦然）⇒ 判定用历史位置、结算在现在时恰一次 |
| T36 | 环越界退化 | 请求 >200ms 历史 ⇒ 退化当前快照 + 告警事件，无崩溃无重复结算 |
| T37 | 重演可复算 | 含回溯判定的对局 Replay 重演 ⇒ 判定结果逐位一致（反作弊闭环） |
| T38 | 预测无 RNG | 静态检查：预测路径不触达 Roll100（ADR-0001 §4.1） |
