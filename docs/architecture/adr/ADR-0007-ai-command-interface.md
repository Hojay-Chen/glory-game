## 0. 背景

AI 的定位是**陪练优先于表演**（GDD §23.1）：使用与玩家完全相同的规则与帧数据，不允许 AI 专属数值。architecture.md 已定 AI.Controller 经 CmdStream 注入（P4）。本 ADR 固化 AI 的接口契约、感知边界、难度实现与确定性。

## 1. 同权契约（本 ADR 核心）

```
AI.Controller ──产出 Command──→ InputPipe ──→ ISimDriver        （与玩家完全同一条路）
      ↑
      └── 感知输入 = ISimView 的【自己视角投影】（见 §2）
```

1. **产入同权**：AI 产出 `Command`（ADR-0001 record），与玩家指令在同一条 CmdStream、经同一合法性裁决——**AI 没有特权指令、没有专属数值**（GDD §23.1 硬规则）
2. **感知受限**：AI 只拿到 `ISelfView`（自己视角投影）——自己的状态/资源/CD/可见实体列表；**不拿到**：对手输入、对手意图、未对自己可见的隐藏单位（VisibilitySystem 过滤）、未来事件
3. **不读输入条款（D25）**：`ISelfView` 不含任何对手输入字段；「传说 AI 会预判」= 决策层统计玩家**历史行为模式**（已发生的公开事件，如出招频率统计）实现，结构上无法偷看

## 2. ISelfView（AI 感知投影）

```csharp
public interface ISelfView {
    int SelfId { get; }
    SelfState Self { get; }                        // 自己完整状态（=快照中自己的部分）
    IReadOnlyList<VisibleEntity> Visible { get; }  // VisibilitySystem 过滤后的可见实体（位置/朝向/状态，无输入）
    // 事件感知：AI 也可订阅 EventBus（同玩家观察能力——只含公开事件；隐藏单位相关事件被 Visibility 过滤）
}
```

- 公平细节：**可见性对称**——若 AI 处于隐身，对手也不可见 AI（同一 VisibilitySystem 投影，无作弊不对称）
- 反应延迟实现：`AI.Controller` 维护延迟队列——感知快照延迟 D ms 后才进入决策（400/250/160/120ms 按难度），延迟本身随 Snapshot 附带的 Tick 数计算，确定性（回放可复算）

## 3. 三层架构落地

| 层 | 实现 | 确定性要点 |
|---|---|---|
| 决策层（效用系统） | `EvaluateUtilities(ISelfView) → 行为权重表`：距离/资源/CD/控制值/连段机会/受身威胁加权 | 效用计算纯函数；并列权重按固定打破序（行为 ID 序） |
| 帧数据层 | 完全读 SkillDef 表决策——知道自己的前摇/取消窗，**不读对手 SkillDef 意图**（对手已释放的技能从公开事件得知） | 数据来自 RuntimeCatalog（同一 Catalog） |
| 反应层 | 延迟队列 + 触发响应（受击→翻滚判定等），延迟按难度常量 | 队列内容随 Snapshot 持久化（重演一致） |

- **假动作**（传说难度）：决策层的低权重诱饵行为选项——是正常 Command 而非特殊机制
- AI 难度只是「同一效用系统 + 不同参数表（延迟/权重/行为池）」——难度数据化，无硬编码分支

## 4. 训练模式挂接（TR-feel-006）

- 对策训练（「只练躲狮子吼」）= AI 行为池白名单参数；木桩 = AI 关闭 + 状态锁定指令；连招实验室 = 输入录制回放（ADR-0005 通道）；镜像对战 = Replay 混合驱动——全部复用既有机制，AI 模块只提供「行为池参数化」入口

## 5. 与种子化随机的边界

AI 决策**不消费战斗 RNG**（SKILL_CHANCE 流）——AI 使用的随机（如行为扰动）走独立 AI_STREAM（ADR-0001 §4.1 AMBIENT 类），且**只影响 AI 自己产出的 Command 时序选择**（进 Snapshot 域，重演可复算）；难度参数表入 Catalog（ADR-0002 管线）

## 6. 测试

| # | 测试 | 验证 |
|---|---|---|
| T49 | 感知边界 | 静态+运行期：ISelfView 无对手输入字段；隐藏实体不出现在 Visible |
| T50 | 同权等价 | 相同 Command 流下，AI 产出的指令与玩家手输指令在 Sim 中结算路径逐位一致 |
| T51 | 延迟分级 | 四档难度延迟队列时序确定，重演一致 |
| T52 | 决策确定性 | 同 ISelfView 同参数 ⇒ 同 Command 序列（效用并列打破序生效） |
| T53 | 不读输入 | 运行期断言：AI 决策函数的输入快照中不存在对手输入通道 |
