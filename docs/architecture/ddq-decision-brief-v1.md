## D1　投技的「落点」与「落地二段伤害」怎么建模

**涉及两行**：`GRP_T1_001 背摔`（柔道家 T1，抓取技，CD 8s）、`GRP_U_001 空中灌篮`（柔道家 U 档，CD 120s / MP 280，倍率 **4.21**）。

**原著原文**

> 5级：背摔：将目标抬过头顶**摔在身后**。目标触地后会产生**小范围震地波，对范围内所有目标附带后续范围伤害**。可破霸体，受身无效。
>
> 空中灌篮：大招，将目标**从高空狠狠掷下**。

**我们已有什么**

- 抓取体系已实现（抓起 / 投技结算 / 第三方免疫 / 无视霸体）。
- 两行的 `status` 已经写着落点参数：背摔 `震地波:r2.5:0.30`（半径 2.5m、倍率 0.30），空中灌篮 `落点AOE:r3.0`。
- 两行的 `special` 都写着 **`落点可控`**。

**缺什么**

1. **落点怎么决定**——"可控"没有定义控制方式：是我们自动算、还是玩家操舵、还是用被抓者的位置。
2. **落地二段伤害在哪一刻、对谁生效**——原文只说"触地后产生震地波，对范围内**所有**目标"（不只是被抓者）。

**选项**

| | 落点 | 二段伤害时机 | 玩家会看到 |
|---|---|---|---|
| **A** | 施法者**背后 1.5m**（贴合"摔在身后"） | 被抓者触地那一帧，对落点 r 内**所有**人结算 | 摔到身后、落地炸一圈，站在附近的人一起挨 |
| **B** | 落点=**被摔者被掷出的抛物线终点**（施法瞬间锁定） | 同上 | 落点取决于摔出去的位置，更像物理 |
| **C** | 引入**操舵**（Steer 改落点） | 同上 | 玩家可以在摔的过程中微调落点 |

**推荐 A**。理由：原著写死了"摔在身后"，A 最贴；B 需要投技与抛物线求解耦合（又是新系统）；C 需要一条新的输入通道（SPEC-0001 要扩），而本技是 T1 小技能，性价比低。

**影响面**：`HitResolve` 抓取结算后新增"落点 AOE"二次判定；`GRP_U_001` 同款复用。约 2 行技能落地。

## D2　`SBL_T3_001 裂波斩` 的「结界:封锁1.2s」封的是什么

**数据**：魔剑士 T3，CD 25s，倍率 1.10，硬直 20f，`special = 破霸体;封锁抓取技;裂波AOE+炸飞`。

**原著原文**

> 裂波斩：靠魔剑士驾驭的剑意波动来**封锁对手的抓取类技能**。剑锋挑起目标时会形成一个法术结界将其**封锁**，而后产生一个裂波以该目标为中心旋转切割攻击，裂波对周围其他目标也会造成伤害，旋转杀伤结束后裂波会炸开，将目标炸飞。可破除霸体效果。

**缺口**：原文出现了**两个**"封锁"——一个是"封锁对手的抓取类技能"（这是**魔剑士的职业特性**，写在 `special` 里），另一个是"结界将其封锁"（被挑起的目标**不能动**）。`status` 里的 `封锁1.2s` 指的是后者，但没说清禁到什么程度。

**选项**

| | 含义 | 玩家会看到 |
|---|---|---|
| **A** | 目标**不能用抓取类技能**（只解 §special 那条） | 几乎看不出差别，因为禁的是"对手的抓取"，对被挑起者没有束缚感 |
| **B** | 目标**不能移动**（Root 1.2s） | 被挑起的人定在原地挨裂波切割，能出招反击 |
| **C** | 目标**不能行动**（Stun 1.2s，硬控） | 被挑起到裂波炸飞之间完全任你打 |

**推荐 C**。理由：原著"形成结界将**其**封锁"主语是被挑起的目标，且紧接着"裂波以该目标为中心旋转切割"——如果目标能自由行动/反击，这段描述就不成立。1.2s 也是合理的反制时长。

**影响面**：1 行路由（`封锁` → `Stun`）。**同时**：`special` 的"封锁抓取技"是另一件事（魔剑士克制抓取职业），目前未实现，属**独立的职业特性**，不在本条内。

## D3　`ROG_T3_004 霸王连拳` 的「压制」是什么

**数据**：流氓 T3，CD 24s，**6 段**、每段倍率 0.37，`status = 压制:目标倒地期间持续`，`special = 把人按翻在地乱打`，类型=控制技。

**原著原文**

> 霸王连拳：把人**强制按翻在地乱打**。控制技。

**缺口**：字面看是两件事——"强制按翻在地"（造成倒地）与"乱打"（连段伤害）。但 `status` 写的是"**目标倒地期间持续**"，读起来像前提条件而非结果。两种读法的手感差别很大。

**选项**

| | 含义 | 玩家会看到 |
|---|---|---|
| **A** | **本技自己把人按倒**，随后 6 段在倒地态下持续命中 | 起手→对方趴下→被连打 6 下，符合原著"按翻在地乱打" |
| **B** | **只对已倒地目标生效**（未倒地时打空） | 变成"倒地追击技"，要对倒地的人用；空放很尴尬 |
| **C** | 命中后**目标倒地且不能起身**直到连拳结束 | 更强控，接近"锁死" |

**推荐 A**。理由：原著动作是主动的施暴过程，不是机会主义追击。B 会让这技在正常对拼里几乎用不出来。

**影响面**：1 行。若选 C，还要动"起身/受身"规则，影响面更大（涉及 §4.3 与倒地受身体系），不建议。

## D4　`WRK_T3_004 操纵术`（术士 T3）

**数据**：`proj:锁链:16m`，倍率 **0**，CD 25s，前摇 14f / 判定 hold。

**原著原文**

> 操纵术：一道黑光打出，可以操纵黑光所牵的任何东西，是一个**持续消耗法力**的技能。**所操纵目标的重量越大，每秒消耗的法力就越多**。操纵如玩家这样的活物，还另有加成。**法术的牵连可以被攻击斩断。**

**缺口**：这是术士的**职业身份技**（傀儡师玩法），原著的完整形态需要三样我们都没有的东西：①"牵着目标走"的持续操控；②按目标重量扣蓝；③牵连可被第三方攻击斩断。但它的**倍率是 0**——意味着现在这技放出去什么都不会发生。

**选项**

| | 含义 | 玩家会看到 |
|---|---|---|
| **A** | 本期不做，保留未路由登记 | 这技是空的（现状），但不会引入半成品手感 |
| **B** | 简化为**长距离拉拽**（把目标拽过来，或用它位移自己） | 有实际作用、复用已有 Pull 原语；但"操纵"变成"拉一下"，与原著的持续操控差很远 |
| **C** | 完整傀儡：牵连实体 + 持续扣蓝 + 可被斩断 | 真正的傀儡师玩法；需要一个新实体与新状态机 |

**推荐 A（本期）**，把 C 列为术士 Epic。理由：B 会给出**错误的手感**——玩家会以为自己在"操纵"，实际只是一次拉扯，之后改成 C 反而是行为破坏。宁可先空着。

## D5　`WRK_T3_006 鬼影缠身` 的 DoT 每秒伤害是多少

**数据**：术士 T3，`proj:26m/s:16m`，倍率 **1.50**，`status = 附身DoT`，`special = 结束后33%伤害补充为术士生命`。

**原著原文**

> 鬼影缠身：时间内**附身目标制造伤害**，技能结束后，**鬼影飞回，造成伤害的 33% 补充为术士的生命**。

**缺口**：`status` 只写了"附身DoT"这个**名字**，**没给每秒伤害**。倍率 1.50 是命中那一发；附身期间总共打多少，数据里没有。

**选项**

| | 含义 |
|---|---|
| **A** | 按 GDD §7.3 DoT 基准带取中值（我会给出建议值让你确认） |
| **B** | **你直接给一个数**（推荐：这是伤害，CSV 唯一数值源） |
| **C** | 挂白名单，等数据 |

**推荐 B**。理由：DoT 总量直接决定这技强度（还会 33% 回血），不该由实现者拍；给个"总量 = X 点，分摊到 N 秒"即可。

**影响面**：1 行。回血部分复用已有 `Lifesteal` 通道。

## D6　`WRK_T4_002 死亡之门`（术士 T4，70 级）

**数据**：`portal:r3.0:触手18身位`，倍率 2.49，硬直 25f，CD 55s。

**原著原文**

> 70级：死亡之门：技能释放后，门内黑气所凝聚出的**触手一般的线条会自动追击方圆 18 个身位格内的目标**，抓住目标后就会**迅速拉扯到门内**，而后给予**强大的伤害**。

## D7　`WRK_T4_003 幽魂缠绕` 的两个数值缺口（术士 T4，75 级）

**数据**：`deploy zone:r6.0:8s`，倍率 2.30，`status = slow:强;禁闪现`。

**原著原文**

> 75级：幽魂缠绕：在一大片的区域种下诅咒。在技能消失或是走出这片区域前，都会让身陷其中的角色**持续掉血**，另外还有**极强烈的减速效果**。**瞬间移动、影分身术、机械旋翼等瞬间逃离手段，到这片诅咒之地纷纷不好使，全都会被打断，全都会将你扯住。**

**缺口**（两个，都缺数据）

1. `slow:强` **没有百分比**——"极强烈"是形容词，不是数值。
2. `禁闪现`——**我们从来没有闪现/瞬移系统**，所以"禁止闪现"目前没有作用对象。原著真正说的是"**打断并扯住一切瞬移手段**"。

**选项**

| | slow 数值 | 禁闪现 |
|---|---|---|
| **A** | 取 GDD §7.3 最强档（我会给出具体值让你确认） | 登记为无操作（没有闪现系统可禁） |
| **B** | 你给数 | 实现为"区域内**打断并禁止一切位移类技能**"（需要先给技能打位移标签） |
| **C** | 挂白名单 | 同 C |

**推荐：slow 走 B（你给数，或我提两个候选让你选）；禁闪现走 B 的一部分——只做"打断已有的位移手段"**。理由：原著的重点是"打断+扯住"，而"禁闪现"在没有闪现系统的前提下是空条款；但我们的**位移类技能是存在的**（突进/翻滚/瞬移类），可以按"区域内的位移技被打断"落地，这样既忠于原著又不引入新系统。

**影响面**：1 行 + 给位移类技能打一个标签（小改）。

## D8　`WIT_U_001 禁忌大爆炸` 的「全异常满值」（魔道学者 U 档，CD 120s / MP 280）

**数据**：`circle:r6.0`，倍率 **4.30**，浮空 8.0，`special = 蓄力:1.5s;全异常满值`。

**缺口**："全异常满值"要实现成什么。**这里有个技术陷阱**：我们的控制值（Control Value）是**累积**的，**满 100 会触发 Break —— 目标进入 1.5s 免控**。所以如果真的"把控制值拉满"，结果是目标反而**免疫控制**，与技能意图相反。

**选项**

| | 含义 | 玩家会看到 |
|---|---|---|
| **A** | 施加**全部 14 类控制异常**（各按 §7.3 标准控制值增量），**不把控制值拉满** | 目标一口气中一堆异常，被控得死死的 |
| **B** | 全部异常 **+ 控制值直接拉满** | 触发 Break → 目标反而免控 1.5s（除非你要的就是这个"双刃"效果） |
| **C** | 只施加**硬控 4 类**（眩晕/冰冻/麻痹/沉睡） | 更克制，但不像"炼金终极" |

**推荐 A**。理由：这是 U 档大招，A 的压迫感最强；B 会因 Break 机制产生**反直觉**结果，除非你有意如此。

**影响面**：1 行（展开为一个状态列表）。

## D9　`WIT_PAS_001 扫把掌握`：飞行怎么进入

**数据**：魔道学者 T1 被动，`special = 飞行4s(+1);空中连击;凌空判定强`。**飞行原语已实现**（Batch 7 Part 2：重力免除 + 6m 高度上限 + 被击中击坠 + 时长数据化），**只差"怎么起飞"**。

**原著 / GDD**

> 骑乘扫把飞行 + **空中连续攻击**能力；凌空时攻击判定极强（原著）。浮空全职业最差，但空中游击是职业身份。

**缺口**：GDD 只写了"飞行 4s(+1s)"，**没写进入方式**。

**选项**

| | 怎么起飞 | 玩家会看到 / 代价 |
|---|---|---|
| **A** | **跳跃延展**：跳到最高点自动转为飞行 | 手感连贯；但会改变所有人的跳跃终点行为（跳跃成了"准飞行"） |
| **B** | **扫把冲刺中进入**：`WIT_T1_004 扫把冲刺`（`突进:7m:可空中`）在空中使用→接飞行 | 复用已有技能，语义自然（冲刺→滑翔）；需要该技在空中时衔接飞行 |
| **C** | **独立键**：新增一个"起飞"键 | 最可控、不污染既有跳跃/冲刺语义；但多一个按键，且键位表要改（ADR-0010） |

**推荐 B**。理由：**修正我上一版**——`扫把冲刺` 本来就注了"可空中"，把它作为起飞入口既贴合职业动作，又不新增按键、不改跳跃语义。A 的副作用（污染跳跃）是我现在最不想要的。

**影响面**：1 行被动 + 1 行技能的接线；飞行原语已就绪。

## D11　`QIM_T2_002 念气罩` 要真的"吸收伤害"吗

**数据**：`circle:r3.5:耐久2000`，`special = 吸收一切攻击伤害:可被击破`。

**原著原文**

> 25级：念气罩：一个肉眼可见的光罩，**任何攻击伤害都可悉数吸收**。持续时间 30 秒，但在对手的强力输出下**也可能提前就被击破**。

**现状**：v1 把它做成 `Zone` 实体（有耐久 2000 的静置物）。**但它不吸收任何伤害**——耐久目前只是"被打会掉"的数值，罩内的人照样全额挨打。

**选项**

| | 含义 | 玩家会看到 |
|---|---|---|
| **A** | 维持 v1 | 罩是个摆设，与原著宣传的作用完全不符 |
| **B** | 罩内**友方**受击时，伤害**转移到罩的耐久**上；耐久归零→罩碎、恢复正常受伤 | 罩真的能挡伤害，打光耐久就破——忠于原著 |
| **C** | 只是**拦截投射物**（子弹打不进来），近战照常 | 半套；实现简单但漏掉近战 |

**推荐 B**。理由：原著写的是"任何攻击伤害都可悉数吸收"，C 会漏掉近战、A 等于没做。B 的实现落点清晰（受击结算前查"是否在罩内"）。

### C1a 落地时的两处必要偏离（如实记录）

1. **D8 的"按标准增量施加"不可实现**：控制值是**累积**量，14 类增量合计 **315 ≫ 阈值 100**，
   按常规注入必然触发 **Break（解除一切控制 + 1.5s 免控）**——目标**反而免控**，与本技意图相反。
   故实现为「施加全部异常 + **本技不注入控制值**」（新增数据位 `SuppressControlValue`）。
   这忠实地落实了原推荐的"不把控制值拉满"这一意图；SR11 用**反证**锁死了它
   （照常注入 → 断言目标确实 Break），防止后人"顺手"删掉这个数据位。
2. **禁足「无法解除」暂未实现**：需要给 `StatusInstance` 加"不可净化"标记并改 Cleanse 判定，
   属额外管道。本次只落了 `Root 3.5s`；「无法解除」留待下一批（已登记，未声称完成）。

### 顺带发现的两个既有缺陷

- ~~**`Weakness`（虚弱）对攻击完全无效**~~ ✅ **已修（C1b）**。三重缺陷叠加：①`AtkMultQ()` 全项目无人调用；
  ②`虚弱` 路由时把 `ATK-20%` 的数值丢成 0；③`AtkMultQ` 硬编码 20% 使数据无法覆盖。
  现改为：PotencyQ 有效则按数据、缺省回落 §7.3 基准 20%；`HitResolve` 接入消费点。
  影响面实测很小——全表只有 1 个技能（`ROG_T3_003 恐吓`）带 虚弱。
- **`禁闪现` 是空条款**：本作无闪现/瞬移系统可禁（D7 已按原著本意改判为"区域内打断位移类技能"）。
  目前只做了"消费为无操作"，**D7 的实义尚未落地**。
- **`slow:强` 是第二个同类静默缺陷** ✅ 已修（PATCH-023）：`强` 不是数值，`ParsePercent` 解析失败
  → Potency=0 → `MoveSpeedMultQ` 里 `mult -= min(0,1)` 等于没减 → **幽魂缠绕一点都不减速**。
  这与「虚弱」是同一类问题（**声明了机制却从未产生效果**），值得回头全表排查一遍同类记号。
- **鬼影缠身的「结束后 33% 伤害转生命」未落地**：属独立机制（DoT 结算钩子），已登记待办。
