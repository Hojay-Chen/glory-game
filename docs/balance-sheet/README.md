## 1. 定位

Balance-Sheet 是**平衡层的工作台**：Skill-Spec 管「每个技能的数值是什么」，本目录管「这些数值放在一起是否成立」——定价带、TTK、连段预算、职业面板、MP 经济、武器影响上界。

- **改数值 → 只改 CSV**（skills.csv / class-base.csv / weapons.csv），然后重跑审计；本目录不放技能数值
- **改口径（定价带/TTK 目标/红线）→ 先改 GDD §2.5/§8.5/§9.2，再重跑审计对齐**
- 审计报告结论分级：PASS（无发现）/ CONCERNS（有待裁定项）/ FAIL（红线违规）

## 3. 审计维度（balance-report.md §1–§8）

1. **§9.2 定价带**：直伤技有效倍率（多段合并：`0.30x2` 或 `mult×hits`）逐档对照名义带；MP/CD 分布对照。功能技（控制/召唤指挥/部署/结界/治疗）倍率越带属合法定价，单列为复核项而非违规
2. **TTK 自洽性**：全技能轮转理论 DPS（Σ 中位倍率×ATK/中位 CD 分档求和）对照 §2.5.4 目标带，名义带与实测各算一遍
3. **单发标定**：对等防（ATK×0.6）单发伤害占 HP 比；非 U >25%、U >35% 标记
4. **连段红线**（§8.5）：各职业最高有效倍率×3、含递减折减 0.85 的理论三连爆发，>45% HP 超线
5. **MP 经济**：全部主动技总消耗对照 MP 1000 + 自然 20/s（全套放不完一轮 = 设计意图）
6. **面板红线**：ATK/DEF 带、HP/MP 统一
7. **武器影响上界**：atk_spd/atk_mod 区间 → 同职业理论 DPS 差上界，§16.26 使用率监控兜底

## 4. 平衡流程（§25.2 复述与落点）

```
发现问题（审计/对局数据） → 按 §25.2 优先级选旋钮：
  调数值（倍率/CD/MP，改 skills.csv）
  → 调帧数据（前后摇 ±2f，改 skills.csv）
  → 调规则（取消窗/控制值，改 GDD+实现注记）
  → 改机制（最后手段，走 ADR）
→ 重跑 tools/balance_audit.py + tools/validate_skills.py（+改武器则 validate_weapons.py）
→ 测试服验证 1 周（§25.4）
```

- 每次平衡改动在 balance-report.md 追加变更记录（日期/范围/原因/审计结论变化）
- 帧数据单次调整 ≤±2f；控制值/浮空衰减等规则参数变更视为机制级，走赛季节奏
