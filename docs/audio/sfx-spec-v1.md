# 音效规格 v1（SFX Spec）

> 建立于 2026-10-11。**零外部音频素材**——全部由 `src/Arena.Client/Audio/SfxSynth.cs` 在运行时程序化合成。
> 验收门槛见 `docs/PRODUCTION-PLAN.md` §2.4。

## 0. 为什么用合成

- 本项目无音频素材库，也不下载第三方素材（版权与来源不可控）。
- 打击类音效的核心不是音色复杂度，而是 **瞬态 + 包络 + 层次**。合成完全够用，
  且天然满足"体积为 0、可控、可版本化"（波形由代码与固定种子决定，可复现）。

## 1. 声音层次（Loudness Hierarchy）

**这是打击感的第一原则**：不同事件的音量必须拉开档次，否则玩家听不出轻重。

| 层次 | 事件 | 目标音量（dB） | 合成峰值 |
|------|------|----------------|----------|
| L0 终局 | 对局结束 | −8 | 0.62 |
| L1 重击 | 伤害 ≥ 2000 的命中 | **−5.5** | 0.78 |
| L1 弹刀 | 完美格挡 | **−5.0** | 0.66 |
| L2 中击 | 伤害 800–1999 | −8.0 | 0.78 |
| L2 倒地 | 强制倒地/落地 | −7.0 | 0.74 |
| L2 阵亡 | 阵亡 | −4.0 | 0.60 |
| L3 轻击 | 伤害 < 800 | −11.0 | 0.62 |
| L3 格挡 | 普通格挡 | −9.0 | 0.66 |
| L3 浮空 | 击飞 | −9.0 | 0.60 |
| L4 挥空 | 技能/普攻起手 | **−17.0** | 0.55 |
| UI | 菜单移动/确认/取消 | −20 ~ −16 | 0.5 |

> 挥空（L4）刻意压得很低（−17dB）：它是"呼吸声"，只提供节奏，**绝不能盖过命中音**。

## 2. 音色设计（按事件）

| 音效 | 合成法 | 设计意图 |
|------|--------|----------|
| `Swing` 挥空 | 低通噪声 + 正弦包络（起-落对称） | 破空感，无音高（避免乐音化） |
| `HitLight` | 瞬态噪声（15ms 衰减）+ 190Hz 下扫正弦 | 轻击＝"啪" |
| `HitMedium` | 同上，108→150Hz、时长 105ms | 中击＝"砰" |
| `HitHeavy` | 同上，时长 165ms、体感更重 | 重击＝"轰"，能感到胸腔 |
| `Guard` 格挡 | 1180/1760Hz 双正弦拍频 + 6ms 噪声前沿 | 金属"叮"，不成谐波比才好听 |
| `Parry` 弹刀 | 1620/2440Hz，时长更长的明亮金属 | 全频段最亮的一击——弹刀是"高光时刻" |
| `Launch` 浮空 | 260→900Hz 上行扫描 200ms | 上行＝被抬起 |
| `Down` 倒地 | 92Hz 低频 + 噪声尾 | 身体砸地 |
| `Death` 阵亡 | 420→90Hz 下行扫描 550ms | 下行＝终结 |
| `MatchEnd` 终局 | 110/165/220Hz 三和弦缓起 | 落幕感；**刻意不用胜利号角**（廉价煽情） |
| `UiMove` / `UiConfirm` / `UiCancel` | 单音 blip / 双音上行 / 双音下行 | 菜单语义 |

## 3. 反"机关枪"（专业与业余的分水岭）

连击时若同一个波形反复原速播放，听感会变成廉价的"哒哒哒"。因此：

- 每次播放施加 **±5%~±10% 的随机音高微扰**（`AudioDirector.Play` 的 `pitchJitter`）。
- 打击类按伤害分三档，连段中音量与音高都在变化。
- 挥空音的 jitter 最大（±10%），因为它出现最频繁。

## 4. 工程约束

- 波形在 `SfxSynth` 内**惰性合成并缓存**（每个音效只算一次）。
- 生成后做**去直流 → 峰值归一 → 首尾各 2ms 淡入淡出**：消除 DC 偏移与爆音（click）。
- 12 声部轮转池（`AudioDirector`）：连击叠加够用，且不会无限增长节点。
- 声部池、音量、jitter 均属**表现层**：不读 Sim、不影响确定性。

## 5. 已知缺口（登记）

- **Bus 未分类**：目前全部走 Master；正式应分 SFX / UI / Voice 三条总线并各自限幅。
- **3D 空间化未做**：`AudioStreamPlayer3D` 可按距离衰减/声像；1v1 视角固定，优先级低。
- **无 BGM**：本作当前无音乐；若要，应按"备战 / 对战 / 终局"三段。
- 以上均登记在 `docs/OPEN-ISSUES.md`（UI/ART 组）。
