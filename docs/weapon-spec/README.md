## 1. 设计原则（GDD §15 复述与细化）

1. **武器不是养成对象，是职业身体的延伸**——决定普攻模组（动作/距离/速度/判定形状）与基础攻速基调
2. **每职业 3 把：制式（均衡）/ 特化 A / 精工（一条规则级特性）**；赛前选 1，构筑锁定后不可换
3. **精工特性必须是规则级而非数值级**（GDD D12）——伤害 +8% 这类禁止；「普攻第五段改为浮空」这类允许
4. **武器不改技能数值**——技能参数独立于武器（GDD §15.4）；武器只影响普攻链与攻击节奏
5. **攻速基准**：以该职业制式武器 = 1.00；特化/精工在 0.80–1.25 区间浮动
6. **重量**（GDD §2.1.3）与武器正相关：轻（法器/匕首/手枪）/ 中（剑/爪/弩）/ 重（巨剑/重火器/盾），影响受击反馈不影响移速

## 2. 字段字典（weapons.csv，13 列）

| 列 | 类型 | 说明 |
|---|---|---|
| weapon_id | string | `W_<职业缩写>_<序号>`，序号 1=制式 / 2=特化 / 3=精工 |
| weapon_name | string | 中文名（制式名 / 特化名 / 精工名） |
| class_id | enum | 绑定职业（Skill-Spec §2 缩写表）；UNS 固定唯一「万象伞」 |
| type | enum | 武器大类：sword/heavy_sword/magic_sword/katana/spear/staff/wand/broom/glove/claw/gauntlet/pistol/crossbow/cannon/mech_pistol/scepter/scythe/shield_sword/dagger/twin_sword/umbrella（v0.1.1 补充 dagger 匕首 / twin_sword 双剑——刺客/盗贼谱系；步枪类型待弹药师 v0.2 扩展时再增） |
| grade | enum | standard（制式）/ special（特化）/ masterwork（精工） |

| atk_spd | float | 攻速倍率（制式=1.00） |
| range_m | float | 普攻有效距离（随职业攻距档，GDD §15.2） |

## 3. 特性平衡规则

1. **同职业三把的理论胜率差 ≤3%**（GDD §25.3）；监控指标：使用率应落在 25–45% 区间（GDD §16.26）
2. **特性参数优先可调**：每版本平衡调整优先调精工特性参数，不动攻速/攻击力（GDD §16.26）
3. **特性不与技能联动叠加**：武器特性只作用于普攻/通用层，不修改任何技能参数（GDD §15.4 铁律）
4. **万象伞例外**（GDD D13/D14）：散人唯一武器不可更换、六形态对应六类制式武器模组、无精工特性（形态切换即其特性）

## 4. 主数据（weapons.csv 生成规则）

- 24 职业 × 3 把 = 72 行 + 万象伞 1 行 = **73 行**；剑客「剑五类」（重剑/大剑/短剑/太刀/光剑）v0.1 先落 3 把，大剑/光剑随 v0.2 扩展（notes 已标）
- 攻速/距离按 GDD §16 图鉴照录；特性按「规则级」口径复核——**10 条数值级特性按 D12 规则化改写**（重剑·镇岳/裂地重刃/饮血/崩玉/淬毒爪/暗手/圣佑/重盾套装/誓约，及「影 cutting·忍刀」正名为「影切·忍刀」），明细见 validation-report 变更记录
- 名称与出处保留 GDD §16 原文（除上述正名）；「原著明示武器类型」（剑客五类剑/枪炮师手炮/忍者忍刀/驱魔师战镰/刺客匕首双剑）标入 notes
- v0.1 攻击力修正（atk_mod）仅重武器交换型武器赋值（+2%~+5%），其余置 0——平衡期按 §16.26 优先调特性参数，不动攻速/攻击力

## 5. trait_rules 语法（程序消费）

- 分号分隔多条规则；每条格式：`<目标>(<skill_id 可选>):<参数> <旧值>→<新值>`
- 目标可以是具体技能（引用 skill_id，校验器核对存在性与旧值）、职业机制（如 `召唤兽:` `部署位:` `结印:`）或全局层（`浮空类技能:`）
- 旧值必须与 skills.csv 当前值一致（校验器逐条核对）；不一致 = GDD-GAP，先改 CSV 或改 GDD 再重跑校验
